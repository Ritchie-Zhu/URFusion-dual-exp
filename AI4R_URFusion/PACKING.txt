打包说明（给负责人 / AI4R 的材料包，与 GitHub 仓库链接分开）

仓库链接只负责让它看代码和实验目录，不必在 README 里介绍 URFusion 论文。
下面这个压缩包才是「材料 2–5」。不要把 datasets、*.pth、融合 RGB 大图打进去。

建议文件名: URFusion-visir-exp_AI4R.zip

URFusion-visir-exp_AI4R/
  00_DIRECTION.txt              <- 意向合作方向（现 AI4R_URFusion/DIRECTION.txt）
  01_LINKS.txt                  <- 仓库 URL + 官方论文仓
  02_paper.pdf                  <- URFusion/paper.pdf（材料 2）
  03_repro_six_col.txt          <- 人工复现 6 列（材料 3）
  03_experiments_inventory.txt  <- S1 / moe_update / moe_2 / moe_3 路径
  03_Final_selected.xlsx        <- 对 7 方法主表（可选，来自 metrics_save）
  04_hardware_env.txt           <- GPU / 时间 / 环境
  04_failures.txt               <- 失败设计摘要
  04_logs/                      <- 过程 log（材料 4）
      Fusion_noleak_1.log
      Abl_wo_Dual.log
      Abl_wo_MoE.log
      Abl_SR_wo_Res.log
      SpatialResMoE_1.log
      SpatialResMoE_2.log          <- moe_update 早期饱和
      SpatialResMoE_3.log
      SpatialResMoE_3_eval.log
      SpatialResMoE_2_moe2.log     <- vis-ir-gray-moe_2
      SpatialResMoE_2_eval.log
      ConflictAdd_1.log
  04_metrics_json/              <- 各方法 metrics_summary.json 摘录（不要整库 results/）
  05_AI4R_prompt.md             <- 人类 idea 引导 prompt（材料 5）

  任何 *.pth / *.pt
  **/results/ 融合图
